# Bubble OCR retry — removed

The owner requested removal on 2026-10-20. Single-bubble retry and redraw are no
longer available. Check OCR remains a review indicator; manual OCR text editing
and ordinary page/area Rescan remain available.

The feature was introduced in `304040a` and its multiple-part handling was fixed
in `01e1003`. Both changes were removed before installer publication. Historical
verification and platform limitations remain in the dated entries of the
[implementation plan](implementation-plan.md) and [changelog](../CHANGELOG.md).

The [roadmap](feature-roadmap.md#deferred) marks this feature deferred. There is
no scheduled reimplementation.
